# 🌐 Ádám Csider — Personal Portfolio Website

This repository contains the source code for my personal portfolio website, automatically hosted and published via **GitHub Pages**.

- **Responsive Design:** Optimized layout ensuring a seamless user experience across mobile, tablet, and desktop screens.
- **Performance & UI/UX:** Built with a minimalist approach prioritizing fast load times and clean aesthetics.
- **Continuous Updates:** Frequently updated as I build new projects and expand my tech stack.
